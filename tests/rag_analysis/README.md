# RAG Analysis & Test Results

This directory contains test results and analysis visualizations for the RAG (Retrieval-Augmented Generation) system.

## Results Directory

The `results/` folder contains visualization outputs from RAG system testing:

### Performance Metrics
- `01_success_rate_by_category.png` - Success rates broken down by document category
- `02_keyword_detection_rate.png` - Keyword detection accuracy across queries
- `03_retrieval_rate_by_category.png` - Document retrieval rates by category
- `06_overall_results_pie.png` - Overall system performance summary

### Ranking Analysis
- `04_document_rank_distribution.png` - Distribution of relevant documents by rank position
- `05_success_vs_rank.png` - Relationship between success and document ranking

### Detailed Analysis
- `07_detailed_heatmap.png` - Comprehensive heatmap of test performance
- `rag_test_heatmap.png` - RAG test performance heatmap
- `rag_test_results.png` - Complete test results visualization

## Test Date
Analysis performed: December 9, 2024

## Notes
These visualizations help evaluate the effectiveness of the RAG system in:
- Retrieving relevant clinical pathway documentation
- Ranking results appropriately
- Detecting key medical terminology
- Overall query accuracy
